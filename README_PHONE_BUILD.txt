PHONE-ONLY BUILD (GitHub Actions)

No PC or Android Studio is required.

1. Create a GitHub account if needed.
2. Create a NEW repository, e.g. PH-Sat-Finder.
3. On your phone, use Termux to unzip this project and push the files to GitHub.
4. GitHub Actions builds the debug APK automatically.
5. Open the repository -> Actions -> Build PH Sat Finder APK -> latest run.
6. Download the artifact named PH-Sat-Finder-debug-APK.
